# recipes

My favorite recipes in markdown format

### Why?

I generally find a new recipe online I want to try, and learn to make it or something similar using ingredients I can source locally.  Often I read several recipes, and make my own using my favorite techniques from multiple sources.  If I like it, I'll save the link(s) to use again later.  If I end up making something multiple times, I generally want to a local copy, whether that is a Word document, a website printed pdf, or a paper copy.  I've been burned by only using bookmarks, and a few years later my bookmark is no good because the author deleted the recipe, the website was rebuilt so old URLs no longer work, or the website simply goes offline.  

Recently, I was using PDFs and Word documents stored locally and backed up to the cloud.  Organization and memory of where I put them was always a problem.  My favorite recipes were printed because I referenced them often, devices fail faster than paper does, and the risk of damaging a device in the kitchen goes to 0 if you don't use a device in the kitchen.  

It occurred to me recently that git and github are a great solution to this problem of having a single respository of this data that is distributed to all devices.  My recipes do change over time, and having git log those changes might be interesting.  I chose markdown because I needed a text-based document for git to be useful.  It has just enough formatting for my needs.  I prefer the *Joy of Cooking* style of recipe writing, that uses **bold** for ingredients as they are introduced rather than a list of ingredients in the beginning.
